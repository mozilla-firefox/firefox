# Git guide

Firefox, including the Android projects, is developed in a git repository.

- To install git and learn its basics, see the [Pro Git book](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git).
- To clone the repository and make your first contribution, see the {ref}`Firefox Contributors' Quick Reference <firefox-contributors-quick-reference>`.
- For more advanced configuration, see {doc}`/contributing/git-tricks` and {doc}`/contributing/stack_quickref`.
- To find an easy first bug, see {ref}`good-first-bug-guide`.
