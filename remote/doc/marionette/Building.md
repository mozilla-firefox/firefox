# Building Marionette

Marionette is built into Firefox by default and ships in the official
Firefox binary.  As Marionette is written in JavaScript, you may choose
to rely on [artifact builds], which will download pre-compiled Firefox
blobs to your computer instead of compiling Firefox locally.

See the {ref}`Firefox Contributors' Quick Reference
<firefox-contributors-quick-reference>` for how to get the source code
and build Firefox, and [Building the Remote Agent] for the build options
specific to the remote protocols, such as `--disable-webdriver`.

[Building the Remote Agent]: /remote/Building.md
