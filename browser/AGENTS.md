# Browser instructions

Scoped guidance for `browser/`. The global `../AGENTS.md` still applies.

Load the `desktop-frontend` skill (`.agents/skills/desktop-frontend/SKILL.md`)
before you edit or review a front-end file here (e.g. `.js`, `.mjs`, `.html`,
`.xhtml`, `.ftl`).

For a CSS task or a Firefox::Theme bug, load the
`desktop-theme` skill (`.agents/skills/desktop-theme/SKILL.md`).

Neither skill covers the C++ and Rust code here.
