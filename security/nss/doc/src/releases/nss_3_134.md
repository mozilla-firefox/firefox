# NSS 3.134 release notes

## Introduction

:::{container}
Network Security Services (NSS) 3.134 was released on *18 November 2026*.
:::

## Distribution Information

:::{container}
The HG tag is NSS_3_134_RTM. NSS 3.134 requires NSPR 4.41 or newer.

NSS 3.134 source distributions are available on ftp.mozilla.org for secure HTTPS download:

- Source tarballs:
  <https://ftp.mozilla.org/pub/mozilla.org/security/nss/releases/NSS_3_134_RTM/src/>

Other releases are available {ref}`mozilla-projects-nss-releases`.
:::
