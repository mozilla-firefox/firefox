# NSS 3.133 release notes

## Introduction

:::{container}
Network Security Services (NSS) 3.133 was released on *4 November 2026*.
:::

## Distribution Information

:::{container}
The HG tag is NSS_3_133_RTM. NSS 3.133 requires NSPR 4.39 or newer.

NSS 3.133 source distributions are available on ftp.mozilla.org for secure HTTPS download:

- Source tarballs:
  <https://ftp.mozilla.org/pub/mozilla.org/security/nss/releases/NSS_3_133_RTM/src/>

Other releases are available {ref}`mozilla-projects-nss-releases`.
:::
